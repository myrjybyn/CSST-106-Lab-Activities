What am I seeing?

An image is an array of pixel values. OpenCV represents a color image as (height, width, channels) and stores channels in blue, green, red order. Grayscale has one intensity per pixel, from 0 (black) to 255 (white). Cropping selects array rows and columns; resizing resamples pixels; rotation changes their spatial arrangement. These operations support applications such as document scanning and preparing images for object detection.

Sobel and Canny: what to compare

Sobel magnitude represents the strength of local intensity changes. It can show broad boundaries and fine texture at different gray levels. Canny uses gradient analysis, non-maximum suppression, and two-threshold hysteresis to produce a binary edge map with thin boundaries. Lower thresholds can retain more detail and noise; higher thresholds can remove weaker boundaries. Inspect your own outputs to see which structures each method retains.

The Sobel preview is scaled from its actual floating-point magnitude range to 0–255 for PNG display. Its brightness is relative to this image; it is not a binary edge classification.

Histogram Equalization and Contrast Adjustment

Upload an image and compare global equalization, adaptive equalization, and linear contrast stretching alongside their intensity histograms.

HistogramsGlobal equalizationCLAHEContrast stretching

01 Set up your experiment

Try an image with low contrast, then compare with a well-lit image.

Processing mode

Grayscale adjusts pixel intensities. Color adjusts only Y in YUV, then converts back for display.

CLAHE settings

Defaults: clip limit 2.0 and an 8 × 8 tile grid. Tile grid means the number of regions, not pixels per tile.

All methods start from the same original intensity channel. Linear stretching maps its minimum and maximum to 0 and 255; a constant channel is left unchanged.
