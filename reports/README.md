# Hard-copy laboratory reports

For each completed activity, include:

- Activity number, title, student name, section, and execution date.
- Objectives and the procedure you actually performed.
- Algorithms or techniques and parameters used.
- Screenshots of the Web UI showing original and processed outputs.
- Results, your observations, and your conclusion.

Write your report yourself using your preferred document editor, export it as PDF, and copy it into this folder. The website displays your files; it does not write report answers.

## Naming and viewing

- `reports/lab_01.pdf` associates the PDF with Lab Activity 1.
- `reports/lab_02.pdf` associates the PDF with Lab Activity 2.
- `reports/lab_01/my-report.pdf` also associates it with Lab 1, allowing several PDFs per lab.
- Other PDF filenames appear in the Reports tab as general reports.

Open the website's **Reports** tab and click **Refresh reports** after adding or removing a file. Select **View PDF** to read a report within the website, or download/open it separately. Lab 1 also has its own report section, available before running an experiment. PDF files are tracked by Git for instructor review.

Use screenshots and results from your actual experiment. Review and print your completed PDF for the required hard-copy submission.
